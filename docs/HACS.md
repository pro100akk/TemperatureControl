# Публикация и версии

## Установка

Порядок установки через HACS и вручную приведён в [README](../README.md). Для установки через HACS требуется публичный репозиторий. Видимость репозитория не меняется скриптами проекта.

## Нумерация версий

Единственный источник версии интеграции — поле `version` в `custom_components/apartment_comfort/manifest.json`. Используется формат `MAJOR.MINOR.PATCH`, например `0.2.0`, без идентификаторов сборки. Карточка устройства и диагностика читают эту же версию. Архив называется `apartment_comfort-<версия>.zip`.

Для каждой опубликованной версии создаётся тег `v<версия>` и GitHub Release. Пользователям рекомендуется устанавливать релизы; установка основной ветки может отображаться как ревизия разработки. Уже установленные файлы и карточка устройства обновляются после установки релиза и перезапуска Home Assistant.

## Подготовка релиза

1. Обновить версию в манифесте и описание изменений в `CHANGELOG.md`.
2. Выполнить `python tools/build_assets.py`, сохранить сгенерированные переводы вместе с исходниками.
3. Выполнить `python -m unittest discover -s tests -v` и `python -m compileall -q custom_components tools tests`.
4. Проверить метаданные: `python tools/configure_repository.py --check --repository OWNER/REPOSITORY --tag v<версия>`.
5. Отправить проверенный коммит и соответствующий тег в GitHub.
6. Дождаться успешных проверок Validate и Release, проверить наличие архива на странице релиза.

Workflow Release сверяет тег с манифестом, запускает тесты, собирает архив и публикует именованный релиз. Если GitHub Actions недоступны, тот же архив можно опубликовать вручную из проверенного коммита. Теги уже опубликованных версий не перезаписываются; исправления выпускаются с новым номером.

## Проверки репозитория

- Validate проверяет тесты, синтаксис Python, метаданные и воспроизводимость переводов.
- Для публичного репозитория дополнительно выполняется HACS validation. Проверка brands отключена для пользовательского репозитория.
- Публикация запускается по тегам `v*`; права записи выдаются только заданию создания релиза.
- Workflows не подключаются к Home Assistant и не управляют оборудованием.
- При переносе проекта метаданные можно настроить командой `python tools/configure_repository.py --repository OWNER/REPOSITORY --maintainer GITHUB_USERNAME`.
