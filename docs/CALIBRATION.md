# Калибровка теплового влияния

Настройки находятся в разделе управления интеграции. Коэффициенты используются в предварительном прогнозе и не изменяют непосредственно пороги включения устройств. Обучение автоматически оценивает суммарную скорость изменения температуры для наблюдаемого режима; отдельные физические коэффициенты из неё однозначно не определяются.

## Сравнительные проверки

1. Выберите период без готовки, прямого солнца и изменения других источников тепла. Используйте актуальные комнатный и наружный датчики. Зафиксируйте состояния приборов и скорость вытяжки.
2. Дождитесь стабилизации после переключения. Запишите начальную и конечную температуру за одинаковые интервалы, например 20–30 минут. Проведите несколько повторов; одиночный результат не считается калибровкой.
3. Повторите наблюдение, изменив только один фактор: окно, вытяжку, обдув радиатора либо источник тепла. Для обдува радиатор должен действительно нагреваться в обоих интервалах. Окно и наружная температура должны оставаться сопоставимыми.
4. Рассчитайте скорость `r = (Tконец − Tначало) / длительность_в_часах`. Для дополнительного источника тепла начальная оценка вклада равна `r_включено − r_выключено` в °C/ч. Для охлаждения знак разности обратный.
5. Для окна или вытяжки оценка дополнительного теплообмена равна `(r_включено − r_выключено) / (Tулица − Tкомната)` в 1/ч. Используйте средние температуры интервала. При малой разнице температур результат неустойчив: такой опыт пропустите. Для кухонной вытяжки разделите результат также на долю относительного воздухообмена; команда диммера и воздухообмен не равны.
6. Для доли влияния при закрытом окне сравните дополнительные коэффициенты одной и той же вытяжки при закрытом и открытом окне. Отношение должно укладываться в диапазон 0–1; выход за пределы означает, что условия опыта или приближение модели не подходят. Для компьютера разделите дополнительную скорость нагрева на среднюю мощность в кВт.
7. Введите согласованный результат нескольких повторов в настройки. Проверьте прогноз на независимых интервалах. Отрицательные значения ожидаемого нагрева или большая разница между повторами требуют повторного наблюдения, а не автоматического сохранения.

Фоновый теплообмен нельзя надёжно определить, если в контрольном интервале остаются неизвестные источники тепла. Настройки окна и вытяжек — эффективные коэффициенты модели, не замена измерению расхода воздуха. Кривая команды вытяжки калибруется отдельно по измеренному относительному воздухообмену.

## Автоматическое обучение и активные тесты

Пассивное обучение уже выполняется автоматически при включённой настройке обучения: используются стабильные участки от пяти минут, минимум 12 наблюдений для готового прогноза, контроль ошибки и наружных условий. Наблюдения сохраняются; отдельный режим учитывает вытяжку душа и при закрытом окне. Коэффициенты начальной модели автоматически не перезаписываются.

Активные автоматические тесты с переключением приборов в этой версии не запускаются. Для надёжного расчёта отдельных коэффициентов необходимы контрольные интервалы, стабилизация, проверка внешних вмешательств и оценка достоверности каждого фактора. Одновременная работа устройств и тепловая инерция не позволяют приписать весь измеренный эффект одному прибору. Сравнительные проверки выше позволяют оценить пригодность данных до добавления такого мастера.
